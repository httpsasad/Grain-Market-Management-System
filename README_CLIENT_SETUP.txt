=======================================================================
            CLIENT LAPTOP SETUP INSTRUCTIONS (MANDI ERP)
=======================================================================

1. Install Python (if not already installed):
   - Download Python 3.10 or higher from https://www.python.org/downloads/
   - VERY IMPORTANT: Check the box "Add python.exe to PATH" during installation.

2. One-Time Setup:
   - Double-click on "Setup_Requirements.bat"
   - Wait until it says "Setup Completed Successfully!".

3. Daily Usage / How to Run App:
   - Double-click on "Start_Mandi_ERP.bat"
   - The app will automatically open in your web browser at:
     http://localhost:8000

=======================================================================
                   CREDENTIALS & INITIAL USAGE
=======================================================================
- Default login page: http://localhost:8000/login
- Click "Create New Shop Account" on the signup page to register client's shop.
- Support & User Guide is available on the top bar ("Mandi Guide").
